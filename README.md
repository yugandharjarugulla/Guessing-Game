# Number Guessing Game
This project was developed as part of the **Coursera - Python 101: Develop Your First Python Program** course.

## Features
- Generates a random number between 1 and 100.
- Accepts user input.
- Validates the input range (1–100).
- Displays whether the guess is:
  - Correct
  - Too High
  - Too Low
- Reveals the randomly generated number.

## Technologies Used
- Python 3
- random module

## Learning Outcomes
- Variables and data types
- User input (`input()`)
- Conditional statements (`if`, `elif`, `else`)
- Random number generation
- Basic program logic
